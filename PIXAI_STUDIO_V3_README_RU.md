PixAI Studio v3: настройки разбиты на три сворачиваемые группы (основные, дополнительные, LoRA). При уходе с поля API-ключа принудительно сохраняются настройки SillyTavern (если доступен flush). Ключи сохраняются в настройках конкретного экземпляра SillyTavern, но не синхронизируются между разными доменами/URL-источниками: браузеры изолируют их по origin. Для нескольких разных серверов/доменов нужна отдельная безопасная синхронизация, не реализованная в этой версии. Не вводите ключ в публичные чаты. Visual DNA передаётся в PixAI через Scene Blocks/промпт, а не отдельным нативным механизмом PixAI. Живой API-тест ещё не проведён.
